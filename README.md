# dsh-splash-screen

DeepSeek Harness（DSH）的开屏动画插件：页面**首帧**就是一块干净的底 + 一段纯 CSS/SVG 动画，界面就绪后淡出。内置 10 个动画（棱镜 / 极光 / 涟漪 / 轨道 / 扫描 / 星芒 / 六棱 / 点阵 / 脉冲 / 弧光），在设置页的画廊里点选即预览。

- **不写主题**：不注册主题、不覆盖任何 `--dsw-*` 变量；只在退场前**读一次** `--dsw-alias-bg-base` 让底色对齐你当前的主题。
- **不卡应用**：splash 只是盖在上面，React 照常挂载；动画只动 `opacity` / `transform`，零网络请求、零图片、零字体。
- **不会永久遮挡**：自带 3s 的 CSS 兜底退场；点击 / 任意按键可立即跳过；`prefers-reduced-motion` 下只留一次淡出。
- **卸载无残留**：注入的样式与节点都随插件行一起消失，DOM 里不留全局样式。

## 安装

**从 npm（推荐）**，在 DSH 的插件页搜索 `dsh-splash-screen` 安装，或让 agent 执行：

```
plugin_manager install_bundle  target=dsh-splash-screen
```

**从源码目录安装**（开发时用）：

```
plugin_manager install_bundle  target=/绝对路径/dsh-splash-screen
```

装完后**完全退出应用再打开**（不要只刷新页面）。

原因：桌面端在启动时缓存一份客户端插件清单与 bundle 快照；插件被启用/禁用、或 `client.js` 被改过之后，刷新页面可能用到过期的清单，导致「入口导入失败」——DSH 会把客户端插件激活失败当成致命错误并退出。重启应用会重建这份清单。

后续修改插件代码同理：改完 → 重启应用 → 再看效果。

## 配置

在 profile 的 `cordis.patch.yml` 里按 `id: splash` 覆盖（整份 config 会被替换，缺省字段用插件默认值）：

```yaml
- id: splash
  config:
    holdMs: 1750       # 最短停留，避免一闪而过（0–6000，默认 1750）
    maxMs: 4000        # 最长停留，到点无条件退场（800–12000，默认 4000）
    quietSeconds: 3    # 同一标签页内再次刷新不重播的静默窗（0–3600，默认 3）
    enabled: true      # false = 完全不注入
```

## 设置（应用内）

**设置 → 通用**里有一行「开屏动画」：开关 + 快 / 标准 / 慢（按 `0.75 / 1 / 1.35` 缩放全部时长，含最短停留）。

**设置 → 开屏动画**是一整页画廊：

- 点任意卡片 → 上方预览框**立即重播**那个动画，不用刷新、不用重启；
- 「全屏试播」→ 按当前设置把动画全屏播一遍，点任意处结束；
- 「刷新页面」→ 手动刷新，看真实的开机效果（换动画后必须刷新才会在下次启动生效）。

偏好存在浏览器的 `localStorage['dsh-splash:prefs:v1']`（`enabled` / `speed` / `animation`），由注入脚本在首帧读取。

与 YAML 的关系：YAML 的 `enabled: false` 是**总开关**（根本不注入），应用内开关是**个人偏好**；两者任一关闭都不显示。Web 模式下如果端口变了，origin 变了，偏好会重置（桌面端 origin 固定，不受影响）。

## 行为

| 时刻 | 发生什么 |
| --- | --- |
| 首帧 | 注入层已可见（React 尚未挂载）：固定底色 + 选中的动画开始播 |
| 0–1700ms | 动画主体（不同动画不同，只有 opacity / transform） |
| 界面就绪 | 浏览器半派发 `dsh-splash:ready`；读一次主题底色，整层 320ms 淡出并移除节点 |
| 兜底 | `maxMs`（默认 4s）到点强制移除；CSS 自带 4.6s 兜底淡出 |

桌面端窗口在页面 `load` 之后才显示，所以窗口第一次可见时 splash 已经在页面上，不会先白一帧。

## 已知限制

- 只接管"页面首帧"。Electron 进程启动到窗口创建之间的原生启动画面不归插件管。
- 每次页面加载都会播（刷新、新窗口、Web 模式新标签）；同标签页 `quietSeconds` 内的刷新会跳过。桌面端"关窗再开"不 reload，不重播。
- 底色对齐依赖宿主 `--dsw-alias-bg-base`；若某个主题只改背景图而没改 token，退场瞬间可能有轻微色差。
- 与其它开屏插件同时安装会叠加（后装的在上层），暂时没有互斥检测。

## 卸载

```
plugin_manager remove_bundle  target=dsh-splash-screen
```

刷新页面即恢复原样；源码目录可以直接删除（安装时若为链接，需保留到卸载之后）。
